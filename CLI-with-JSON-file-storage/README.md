# Minimalist To-Do App (Python)

A lightweight command-line to-do list app built with Python.  
Tasks are stored in a JSON file for persistence.

## Features
- Add tasks: `add Buy milk`
- List tasks: `list`
- Mark tasks as done: `mark 2`
- Delete tasks: `delete 1`
- Exit app: `exit`

## Usage
Run the app:
```bash
python3 main.py
